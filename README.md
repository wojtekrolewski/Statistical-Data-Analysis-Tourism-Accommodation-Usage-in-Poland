# Statistical-Data-Analysis-Tourism-Accommodation-Usage-in-Poland

## 1. Project Overview
This project focuses on statistical analysis of tourism accommodation usage in Poland, based on official public data.
The goal was to explore patterns in tourism activity, identify seasonal and structural differences across regions, and apply statistical methods to support data-driven conclusions.

The analysis was conducted as part of academic coursework, but structured as a practical data analysis case study.

## 2. Objectives
- Analyze accommodation usage trends in Poland
- Compare regions and time periods
- Identify seasonal effects in tourism activity
- Apply statistical inference methods to real-world data
- Translate numerical results into meaningful insights

## 3. Data 
**Source:** Central Statistical Office of Poland (GUS)

**Type:** Aggregated tourism and accommodation statistics

**Characteristics:**
- Official, real-world public data
- Temporal and regional division
- Strong seasonality and external effects (e.g. COVID-19 period)

## 4. Methods & Tools
**Programming language:** R

**Key techniques:**
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Descriptive statistics
- Data visualization
- Hypothesis testing
- Comparative statistical analysis across regions and periods

## 5. Key Steps
#### 1. Exploratory analysis
Understanding distributions, trends, and variability in tourism usage.

#### 2. Seasonality analysis
Identification of recurring seasonal patterns in accommodation occupancy.

#### 3. Comparative analysis
Regional and temporal comparisons to detect structural differences.

#### 4. Statistical inference
Application of hypothesis testing to support analytical conclusions.

## 6.Results & Insights
- Tourism accommodation usage exhibits strong seasonal dependence, with clear peak and off-peak periods.
- Significant differences were observed between regions, reflecting geographic and economic factors.
- The COVID-19 period introduced visible structural breaks in tourism activity.
- Statistical tests confirmed that observed differences were not random, but systematic and data-supported.
