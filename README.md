# Statistical-Data-Analysis-Tourism-Accommodation-Usage-in-Poland

## 1. Project Overview
This project focuses on statistical analysis of tourism accommodation usage in Poland, based on official public data.
The goal was to explore patterns in tourism activity, identify seasonal and structural differences across regions, and apply statistical methods to support data-driven conclusions.

The analysis was conducted as part of academic coursework, but structured as a practical data analysis case study.

## 2. Objectives
- Analyze accommodation usage trends in Poland
- Compare regions and time periods
- Identify seasonal effects in tourism activity
- Apply statistical inference methods to real-world data
- Translate numerical results into meaningful insights

## 3. Data 
**Source:** Central Statistical Office of Poland (GUS)
**Type:** Aggregated tourism and accommodation statistics
**Characteristics:**
- Official, real-world public data
- Temporal and regional division
- Strong seasonality and external effects (e.g. COVID-19 period)
