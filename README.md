# Statistical-Data-Analysis-Tourism-Accommodation-Usage-in-Poland

## 1. Project Overview
This project focuses on statistical analysis of tourism accommodation usage in Poland, based on official public data.
TThe aim was to identify temporal patterns and seasonality in accommodation usage using classical statistical methods.

The analysis was conducted as part of academic coursework, but structured as a practical data analysis case study.

## 2. Objectives
- Explore temporal variability in accommodation usage
- Identify and quantify seasonal effects
- Apply statistical inference to real-world tourism data
- Draw interpretable, data-driven conclusions

## 3. Data 
**Source:** Central Statistical Office of Poland (GUS)

**Scope:** Nationwide, aggregated data

**Characteristics:**
- Strong seasonality
- Sensitivity to external shocks (e.g. COVID-19)
- Real, non-simulated data

## 4. Methods & Tools
**Programming language:** R

**Key techniques:**
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Descriptive statistics
- Data visualization
- Hypothesis testing

## 6.Results & Insights
- A long-term upward trend in accommodation usage can be observed prior to the COVID-19 period.
-  Tourism accommodation usage exhibits strong seasonal dependence, with clear peak and off-peak periods.
- The COVID-19 period introduced a visible disruption in tourism activity.
